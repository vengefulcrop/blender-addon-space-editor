# Reference

Reference material for the pyareas fork: the upstream base, the build
guide, the Blender C/C++ handbooks, the blend file compatibility rules,
and the OKF specification.

- [Upstream Base and Version](./upstream_base.md) — The Blender version this
  fork targets, the upstream commit it sits on, and how to measure the gap.

- [Building This Fork (Windows)](./building.md) — The Windows build
  procedure: environment, one-time setup, build commands, timings, and
  gotchas.

- [C and C++ Coding Style](./c_cpp_style.md) — Blender's C/C++ naming,
  formatting, comment, and language conventions not covered by
  clang-format. This file covers the whole source handbook
  (`docs_ui/handbook_c_cpp.md`). No subject inside it was large enough to
  stand alone as a separate file.

- [C/C++ Best Practice](./c_cpp_best_practice.md) — Practical rules beyond
  style: `sizeof` order, unused arguments, and safe string APIs.

- [Blend File Compatibility](./blend_file_compatibility.md) — Backward and
  forward compatibility expectations for `.blend` files, and how to
  handle breakages in development projects.

- [OKF Specification](./okf_spec.md) — The canonical Open Knowledge Format
  v0.2 specification for this knowledge base.
