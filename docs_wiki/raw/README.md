# Raw Notes — Human Only

This folder holds handwritten notes. No AI agent processes them.

**AI agents may read every file here. AI agents must never create, edit,
delete, move, or reformat a file here.**

The notes are the record of user intent: ideas, questions, sketches, and
requirements. They stay in the words the user wrote. Read them to understand
what the user wants. Write the processed result to another section of the
wiki, and link back to the note.

The rules for the folder are in `../CLAUDE.md`, section 1.
