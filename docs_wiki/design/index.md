# Design Specifications

The UX design of the Add-on Editor: how a user discovers, picks, and
navigates hosted add-ons, and what the editor shows when it cannot draw
anything.

- [UX: Editor-Type Picker](./ux_addon_picker.md) — how a user adds an add-on
  to the editor-type dropdown, curates that list, and picks which real editor
  an add-on delegates to.

- [UX: Sidebar and Bookmarks](./ux_sidebar_bookmarks.md) — the Bookmarks and
  Addons sidebar design, what shipped in the first pass, and what is still open.

- [UX: Empty State and Header](./ux_empty_state_and_header.md) — how the
  editor explains why a panel is not drawing, and what the header shows about
  the current delegate.

- [Open UX Requests and Known Issues](./open_ux_requests.md) — the
  outstanding UX backlog captured directly from user notes.
